Sobre a loja

Esta página foi criada com uma estrutura simples para uma loja online fictícia. O tema escolhido foi uma loja de bebidas, usando cards de produtos e um carrinho visual.

O projeto utiliza flexbox, grid, hover, animação simples e responsividade para celular.
